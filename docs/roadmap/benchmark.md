Tests cover ready/missing prerequisites, SDK and credential checks, redaction, and offline network override diagnostics. Local targeted tests passed (6). Acceptance remains open until CI exercises a clean authorized target-only environment with public egress disabled and verifies the resulting actionable diagnostics.

Preflight now rejects `target-only` when the task has no Docker Compose environment network, rejects offline profiles combined with Gateway use, and requires `model-allowed` runs to specify a Docker Agent, sidecar Gateway image and model upstream. It checks that the configured sidecar image is already local without pulling it. The CLI accepts the corresponding Gateway flags so this profile can pass preflight when fully configured. Unit tests cover missing topology and a locally available sidecar case. Docker still needs to verify the environment network's `Internal=true` setting and target-only/public-egress behavior at run time.

Container preflight now runs the same bounded, no-follow task-tree validation used to create the Agent task snapshot. It catches hard-linked inputs, unreadable/changing files, and file-count/size-limit violations before allocating a run or copying a snapshot. A hard-link alias of the configured verifier now fails preflight with an actionable `agent_task_inputs` check and creates no files. Focused preflight/workspace tests passed (17); full suite passed (429 passed, 4 Docker-dependent skips); Ruff, compileall, architecture tests (2 passed), and `git diff --check` passed on 2026-10-09. Docker public-egress acceptance remains outstanding.

Preflight now checks local Gateway sidecar images for every sidecar-mode run, not only `model-allowed`; Pi runs routed through a Gateway require a configured model upstream and no longer incorrectly require a direct provider key. Empty provider-key values from Agent config or host passthrough are reported as missing. Regression tests reproduced both readiness mismatches and now pass (16 preflight tests); full suite passed (467 passed, 4 Docker-dependent skips), Ruff, compileall and `git diff --check` passed on 2026-10-09. The remote model endpoint is intentionally not contacted, so upstream authentication/availability still requires runtime or authorized environment evidence.

### BEN-04 [~] P2 — Reproducibility
Deliver: immutable task/model/container/tool manifests, grader versions and output artifact hashes; distinguish environmental failures from solver failures.
Accept: repeated runs produce comparable metadata and auditable variance; secrets scrubbed.

The evaluation manifest now records the Python implementation/platform, a bounded SHA-256 of the resolved CLI executable, task and grader entrypoint hashes, Agent/model settings, and locally available image IDs. Agent image configuration is represented by a hash; verifier commands are hashed rather than copied, task paths are hashed, and user-controlled labels are redacted. Gateway runs additionally freeze mode, model-upstream fingerprint, pricing rates, policy hash, sidecar image/runtime fingerprints, and whether an API key is configured; credentials and raw upstream URLs are never emitted. Gateway manifest identity participates in baseline compatibility, so cost or routing changes cannot be compared as if they used the same evaluation setup. Each attempt records hashes and sizes for bounded regular files in the Agent workspace; paths are represented only by hashes and Harness protocol files are excluded. Suite reports project attempts into a safe schema and omit exception messages, raw progress and World data. Per-run results and domain summaries distinguish success, solver failure/budget exhaustion, verifier unavailability, environment startup failure, gateway failure, cancellation and harness failure without copying exception text into the classification. The comparator checks every frozen task/seed is present, gates attempt-count mismatches, and reports added, removed and changed output path fingerprints without exposing names. Fresh smoke baselines self-compare; independent repeat runs pass for the smoke suite (2/2 unchanged artifacts) and nine-domain suite (18/18 unchanged artifacts, all domains at 100% success). Regression tests cover secret removal, missing attempts, output changes and duplicate attempt identities. Validation on 2026-10-09: full suite passed (325 passed, 3 skipped), Ruff, compileall, architecture test and `git diff --check` passed; refreshed baselines contain no credential-like strings. The item remains in progress until CI exercises these reports. Output hashing skips links, changing files, oversized files and scans beyond its fixed limits. See [suite tests](../../tests/test_suite.py), [comparison tests](../../tests/test_evaluation_compare.py), and [run tests](../../tests/test_smoke.py).

Gateway manifest regressions verify pricing and routing fingerprints are captured, policy bytes are hashed, and API keys/raw upstream URLs are absent. Comparator tests reject pricing changes. Current validation on 2026-10-09: focused suite/comparison tests passed (14); a nine-domain candidate matched the frozen baseline (18/18 attempts, 18 unchanged artifact sets, no regressions); full suite passed (355 passed, 3 skipped), Ruff, compileall, architecture tests (2 passed), and `git diff --check` passed. This adds fields to the public evaluation manifest; maintainer review is required before merge. CI execution remains outstanding.

Run-result exception messages are now reduced to the exception class plus a generic details-omitted marker before persistence. The trace already sanitizes exception details; this closes the parallel result-artifact leak where an environment/provider exception could include a credential. A regression injects a credential-like canary and checks the serialized result and JSON/JSONL artifacts for its absence. The focused regression passed; full validation on 2026-10-09 passed (400 passed, 4 skipped), Ruff, compileall, architecture tests (2 passed), and `git diff --check`. Four skips are Docker-dependent; CI evidence for reproducibility reports remains outstanding.

Hardened workspace artifact fingerprints against concurrent Agent mutation. Hashing now opens each relative output path with no-follow traversal, hashes from the pinned regular-file descriptor, verifies descriptor and directory-entry identity/size/mtime before accepting the digest, and enforces byte ceilings during reads (not only from the pre-read size). Tests confirm symlinked/oversized artifacts are omitted and a file modified during scanning cannot be recorded as stable. Focused suite/comparator tests passed (20); full suite passed (403 passed, 4 Docker-dependent skips); Ruff, compileall, architecture tests (2 passed), and `git diff --check` passed on 2026-10-09. CI report execution remains outstanding.

Manifest source hashing now uses the same bounded streaming and identity checks for task, suite, Agent, verifier, Gateway policy and CLI executable files. Symlinked or concurrently replaced manifest inputs are refused, oversized inputs fail explicitly, and suite/Agent file fingerprints are captured before the suite begins executing. Focused suite/comparator tests passed (22); full suite passed (408 passed, 4 Docker-dependent skips); Ruff, compileall, architecture tests (2 passed), and `git diff --check` passed on 2026-10-09. CI report execution remains outstanding.

The SuiteRunner Python API now enforces the same 1–64 worker bound as the CLI instead of allowing callers to create an arbitrary ThreadPoolExecutor. Parameterized tests verify zero, over-limit, boolean and non-integer overrides fail before a suite run directory is allocated. Full suite passed (412 passed, 4 Docker-dependent skips); Ruff, compileall, architecture tests (2 passed), and `git diff --check` passed on 2026-10-09.

Target/session metadata, submission metadata, evaluator message/milestones/metadata are bounded and redacted using the shared observability sanitizer; submission metadata is sanitized before it enters World feedback or Agent feedback. Canary tests verify secrets are absent from result, World, trace and workspace artifacts and Agent observations while ordinary evaluation fields remain.
